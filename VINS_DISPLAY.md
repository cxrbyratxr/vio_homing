# Перемещение по оценке VINS в терминале

На Jetson (в том числе по SSH):

```bash
source ~/catkin_ws/devel/setup.bash
unset ROS_HOSTNAME
export ROS_IP=192.168.50.1 ROS_MASTER_URI=http://localhost:11311
rosrun vio_homing vins_displacement.py
```

Открывает отдельный наблюдатель; стек запускается существующим сервисом.
Показывает raw VINS даже при FAULT адаптера, чтобы видеть ошибочную оценку.
Данные и конфигурацию не меняет, команды в PX4 не отправляет.

Ноль — первая свежая поза после запуска. Направление вперёд задаётся курсом
IMU/борта в этой позе, вправо — вправо от него, вверх — по вертикали VINS.
Оси фиксированы при установке нуля, за текущим разворотом борта не поворачиваются.
Это не север/восток и не обязательно направление объектива камеры.

- `r`, затем Enter — новый ноль на следующей свежей позе.
- `q`, затем Enter, или Ctrl+C — закрыть индикатор.
- Знак `+` означает вперёд/вправо/вверх, `-` — назад/влево/вниз.
- Distance — расстояние от нуля по прямой, не пройденный путь.
- STALE, FAULT, POSITION JUMP или STREAM RESET означают ненадёжную оценку.
  Сброс нуля не исправляет VINS и не сбрасывает FAULT управляющего адаптера.

Если odometry ещё нет, показывается ожидание. Если данные прекратились,
последние числа остаются с пометкой STALE. При перезапуске VINS установите новый
ноль; старые координаты разных сессий несопоставимы.
