# Wi-Fi / SSH

Jetson работает как AP VIO-HOMING: 192.168.50.1/24. Сетевой AP независим от ROS.
Сначала подключить Mac к AP, узнать текущий адрес Mac, затем:

```bash
ssh jetson@192.168.50.1
```

В текущем стенде Mac имеет 192.168.50.213. Для другого IP запустить второй
ручной скрипт с `VIO_QGC_IP=адрес_Mac`. Полный порядок: MANUAL_START.md.
ROS_IP на Jetson задаётся env.sh, ROS_MASTER_URI — http://localhost:11311;
старый ROS_HOSTNAME от Ethernet удаляется только в окружении процесса.

Автозапуск ROS отсутствует. Сетевые службы AP/SSH не удаляются.
Браузерное видео и отдельная панель удалены из рабочего запуска.
QGC использует MAVLink UDP; подробности в QGC_WIFI.md.
